# Meu Primeiro PR

Este é um repositório de prática para aprender o fluxo de Pull Requests no GitHub.

## Sobre

Este repositorio foi criado para vocë praticar como abrir, revisar e mergear um Pull Request.

## Como contribuir

1. Crie uma branch a partir da `main`.
2. Faça sua alteração.
3. Abra um Pull Request descrevendo a mudança.
4. Revise e faça o merge.
